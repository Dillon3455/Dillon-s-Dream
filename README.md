# Dillon's Dream

## О проекте

Dillon's Dream — это личный сайт-вики, где собраны знания о разработке игр, вайбкодинге и творческих проектах. Основная часть — **Verse**, база знаний в стиле Fandom-вики.

## Что внутри

- **Verse** — вики-статьи о персонажах (Dillon, Dillon Pro, Dillon Profi, DALAN, Dials, Fi), проектах (ArrowPlex, SurviPlex, PENTALAND) и планах
- **Девлог SurviPlex** — дневник разработки игры с записями о прогрессе, фичах и багах
- **Инфобоксы** — карточки с метаданными для каждой статьи (тип, статус, автор, теги, дата)

## Технологии

- **Astro 7** — статическая генерация
- **Tailwind v4** — стилизация
- **Verse** — Fandom-подобная вики система

## Структура контента

- **`src/content/blog/`** — обычные посты (index.md, about.md)
- **`src/content/blog/verse/`** — вики-заметки
  - `dillons/` — персонажи
  - `projects/` — проекты
  - `devlog-surviplex/` — дневник разработки
  - `plans.md` — планы
  - `start.md` — главная страница Verse
