Этот блог — живое доказательство того, что вайбкодинг работает. Давай разберём, как он появился.

## Что решили делать

- Стек: **Astro** — современный статический генератор
- Стили: **Tailwind CSS** — утилитарный CSS-фреймворк
- Контент: Markdown-посты в коллекции контента

## Порядок действий

1. Создали проект по официальному шаблону блога
2. Добавили Tailwind через `astro add tailwind`
3. Прописали `@import "tailwindcss"` в глобальные стили
4. Написали посты на Markdown
5. Запустили dev-сервер

## Вывод

Статический блог — идеальная задача для начала вайбкодинга: понятный результат, быстрый деплой, куча готовых шаблонов. Попробуйте и вы!
